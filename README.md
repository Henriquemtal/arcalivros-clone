# Arca Livros Clone - Fluxo de Checkout

Este repositório contém um clone funcional do fluxo de checkout do site [arcalivros.vercel.app](https://arcalivros.vercel.app).

## Conteúdo
- `index.html`: Página inicial para inserção do nome da criança.
- `oferta.html`: Landing page com detalhes do livro e ofertas.
- `checkout.html`: Página de finalização de compra e personalização.
- `assets/`: Arquivos JavaScript e CSS originais do site.
- `entregaveis-png/`: Imagens dos bônus oferecidos.

## Como usar
Basta abrir o arquivo `index.html` em qualquer navegador para visualizar o fluxo.
